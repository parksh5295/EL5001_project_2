Run 단위 삽입형 stream 파이프라인 (기존 stream_builder 대체형)
1) run 기반 stream 생성 + RL 비교 one-shot
./run_all_compare_runs.sh --split-mode source --split-ratio "0.7,0.15,0.15" --num-streams 3000 --events-per-stream 120 --min-confidence medium --decision-stride 16 --tabular-episodes 3000 --deep-episodes 3000 --eval-episodes 100
   (기본: 모든 tactic 사용, 일부만 쓰려면 --use-tactics "Credential Access,Discovery")
   (공격 삽입 강도 조절: --attack-runs-max 2 --intra-run-benign-prob 0.05)
   (run 품질 상향: --min-confidence high)
   (저장 경로: 기본은 results/runs_tab..._deep..._eval..._stride... 폴더 자동 생성)
   (직접 지정: --output-dir results/my_exp_001)
   사용 가능한 tactic:
   AutomatedTestingTools, Command and Control, Credential Access, Defense Evasion, Discovery, Execution, Lateral Movement, Persistence, Privilege Escalation
